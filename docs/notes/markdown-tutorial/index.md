# Markdown + VitePress 从 0 到 1 完全指南

> 用一篇教程覆盖：**写 → 写得漂亮 → 写出 VitePress 风格的文档站**。所有示例可直接复制到你的 `.md` 文件里看效果。

## 🧭 章节阅读路径

| 章节 | 谁应该看 | 能学到什么 |
|---|---|---|
| [第 1 章：基础语法](./1-basics.md) | 从没写过 Markdown | 标题、段落、列表、链接、图片、引用、分隔线、代码块、行内代码，够写 80% 场景 |
| [第 2 章：高级语法](./2-advanced.md) | 觉得基础语法不够用 | 表格（含对齐）、任务列表、脚注、数学公式、Mermaid 流程图、HTML 混排、自动链接 |
| [第 3 章：VitePress 专属增强](./3-vitepress.md) | 想把博客写出「文档站质感」 | Frontmatter、自定义容器（tip/warning/danger/details）、代码行高亮与 diff、Badge、Tabs 选项卡、导入代码片段、页面元信息、团队页卡片等 |

## ⏱️ 你需要多久

- 基础语法：**15 分钟** — 看完就能动手写
- 高级语法：**30 分钟** — 第一次查字典用，不用硬背
- VitePress 专属：**20 分钟** — 写博客前翻一遍，选需要的特性就够了

## 🎯 先给你看一个「最小可运行博客示例」

> 把下面这段复制到任何 `xxx.md` 文件里，立刻能看到一篇完整结构的 Markdown 长啥样。

```md
---
title: "我的第一篇博客"
description: "这是 VitePress 专属的 Frontmatter 头信息，第三章会讲"
category: "前端"
---

# 你好，世界 👋

这是我的**第一篇博客**。写博客的三个好处：

1. **复盘** — 把学会的东西讲出来，自己才真的懂
2. **复利** — 半年后回头看，你居然记得这么多
3. **连接** — 陌生人通过你的博客认识你，机会就来了

## 为什么选 Markdown

> Markdown 是一种用**纯文本写排版**的语言。优点是：
> 跨平台、不依赖 Word、Git 能 diff、写博客/文档/笔记全吃得开。

### 我常写的几种格式

- **粗体** 和 *斜体* 组合起来用，比如：
  - `TODO` 列表项可以用 `[ ]` 和 `[x]`
- [x] 已完成：看完基础语法
- [ ] 进行中：看高级语法……
