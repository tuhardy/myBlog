# 第 1 章 · Markdown 基础语法（15 分钟速成）

> 目标：看完本章，你能独立写出一篇**有结构、有代码、有链接、有图片**的 Markdown 博客。

---

## 1. 标题 H1~H6

语法：一行开头写若干个 `#` + 空格，写标题文字。

| 写法 | 效果 | 一般用途 |
|---|---|---|
| `# 标题` | 最大字 H1 | 整篇文章只出现一次，就是文章主题 |
| `## 标题` | 次大 H2 | 章节标题 |
| `### 标题` | H3 | 小节标题 |
| `#### 标题` | H4 | 小要点 |
| `##### 标题` | H5 | 更少用 |
| `###### 标题` | H6 | 最少用 |

**✅ 生动示例（一次看全）**

```md
# 我的周末

## 周六 · 爬山

### 早上出发

###### 凌晨 5 点的闹钟
```

渲染出来会有 6 种大小递减的标题，并且会自动生成**大纲锚点**（鼠标悬停标题左侧会出现 🔗 图标，点它就能复制带锚点的链接）。

## 2. 段落、换行、空行

- **段落**就是连续几行文字，正常写就行。
- **换一行**不会成新段落 —— 必须**空一行**才算新段落。
- 想在**同一段落内强制换行**（比如诗/歌词），行尾打两个空格再回车。

```md
这是第一段。
这句和上面是同一段落，因为没有空行。

这是第二段。（上面空了一行 ✅）

床前明月光，  
疑是地上霜。（每行末尾两个空格 = 同段落内换行）
```

**效果：**

> 这是第一段。
> 这句和上面是同一段落，因为没有空行。
>
> 这是第二段。（上面空了一行 ✅）
>
> 床前明月光，
> 疑是地上霜。（每行末尾两个空格 = 同段落内换行）

## 3. 文本修饰：粗/斜/删/划

| 功能 | 语法 | 渲染效果 |
|---|---|---|
| 粗体 | `**我是粗体**`  或  `__我是粗体__` | **我是粗体** |
| 斜体 | `*我是斜体*`  或  `_我是斜体_` | *我是斜体* |
| 粗+斜 | `***又粗又斜***` | ***又粗又斜*** |
| 删除线 | `~~已经完成的~~` | ~~已经完成的~~ |
| 行内代码 | `` `const a = 1` `` | `const a = 1` |

**🧑‍💼 生活化场景**：写一篇复盘日记

```md
## 本周复盘

工作：这周**终于把那个拖了 2 周的 bug 修掉了**，
但方案评审因为*准备不充分被打回来一次*。

学习：看完 ~~3 本书~~（实际只看完 1 本），
剩下 2 本挪到下周，核心目标是把 `useDebounce` 封装好。
```

> 🎨 **小贴士**：星号 `*` 和下划线 `_` 两种都可以，**全文统一就好**。我个人偏好星号，因为中文混写下划线容易和变量名看混。

## 4. 列表：有序 / 无序 / 任务

### 4.1 无序列表 · `-` 或 `*` 或 `+`

```md
### 周末做什么

- 健身：跑步 5km + 练肩
- 学习：
  - 看完 VitePress 入门视频（子列表，前面打 2 个空格）
    - 第一节：项目结构（孙列表，前面打 4 个空格）
    - 第二节：导航与侧边栏
  - 写一篇博客（子列表）
- 吃饭：和朋友约去吃火锅 + 唱 K
```

- **子列表**：缩进 2 或 4 个空格，**数字随意填、混着写都行**，只要缩进对。

### 4.2 有序列表 · 数字加点

```md
## 做一杯冰美式的 4 步

1. 找一个 500ml 的杯子
2. 倒入 150ml 纯净水 / 矿泉水
3. 接一份意式浓缩（36g 左右）淋在上面
4. 丢 3~5 块冰块，插吸管 ✅
```

**小技巧**：编号写错了 Markdown 也会帮你自动纠正顺序。比如你故意写：

```md
1. 第一步
1. 第二步
1. 第三步
```

照样渲染成 `1. 2. 3.`，批量生成时很方便。

### 4.3 任务列表（待办清单）· `[ ]` / `[x]`

```md
### 今日待办

- [x] 07:30 起床 + 喝水
- [x] 08:30 到公司，处理邮件
- [ ] 10:00 和产品对齐需求（有个坑需要先理清楚）
- [ ] 14:00 写代码
- [ ] 22:00 前睡觉
```

- `[x]` 打钩 = 已完成
- `[ ]` 空格 = 待完成

## 5. 引用块

用一个或多个 `>` 开头，支持嵌套（`>>`）。

```md
> 种一棵树最好的时间是十年前，其次是现在。
>
> —— **出处存疑，但我很喜欢的一句话**
>
>> 嵌套一层：这句话是我对它的注解：
>> 今天开始写博客的你，要比半年后开始的你早半年收获复利。
```

**效果：**

> 种一棵树最好的时间是十年前，其次是现在。
>
> —— **出处存疑，但我很喜欢的一句话**
>
> > 嵌套一层：这句话是我对它的注解：
> > 今天开始写博客的你，要比半年后开始的你早半年收获复利。

## 6. 代码

### 6.1 行内代码 · 一对反引号 `` ` ``

```md
在终端输入 `npm install` 安装依赖，不要用 `cnpm`，包解析不一致容易出玄学 bug。
```

渲染：在终端输入 `npm install` 安装依赖，不要用 `cnpm`……

### 6.2 代码块 · 三个反引号 ``` + 语言名

````md
```js
// 三秒后弹出 hello
setTimeout(() => {
  console.log('hello')
}, 3000)
```
````

加上语言名后，VitePress 会用 Shiki 做**语法高亮**（关键词变色，和 VS Code 里几乎一致）。

常见语言名清单（直接抄）：`js / ts / html / css / bash / json / yaml / java / py / go / sql / sh / vue / diff / md`。

**💡 连写反引号怎么办？** 如果你要在代码块里写 "三个反引号"，外面那一层用 4 个或 5 个反引号包起来就行（层数要比里面多）：

```js
console.log('这里是「代码块里的代码块」示例')
```

## 7. 链接与图片

### 7.1 链接

两种写法：

#### 格式 A · 行内链接（90% 情况用这个）

```md
[VitePress 官网](https://vitepress.dev/)

[带提示文字的链接](https://vitepress.dev/ "鼠标悬停会看到我")
```

#### 格式 B · 引用链接（长文推荐，链接统一放文末）

```md
我每天都看 [VitePress 文档][1] 和 [MDN Web Docs][2]。

文末再统一写：

[1]: https://vitepress.dev/
[2]: https://developer.mozilla.org/zh-CN/docs/Web
```

优点：正文里不掺杂长 URL，可读性好；**同一个链接多次出现只用改一处**。

### 7.2 自动识别链接（<包裹>）

```md
<https://example.com>
<you@example.com>
```

渲染成 <https://example.com> 和 <you@example.com>，自动加 `a 标签`。

### 7.3 图片

图片语法 = 链接前面多一个 `!`：

```md
![这是图片 Alt 文字：加载失败会显示](/avatar.jpg)

![也可以加提示（鼠标悬停出现）](/avatar.jpg "这是我的头像")
```

**👉 在你的 VitePress 项目里**：图片放 `docs/public/` 目录下，路径直接写 `/文件名`。比如：

- 物理文件：`docs/public/avatar.jpg`
- 引用方式：`![头像](/avatar.jpg)` ✅

### 7.4 图片套链接（点图片跳转）

套娃格式就行——外面是链接，里面是图片：

```md
[![一张示例图](https://picsum.photos/400/200)](https://example.com/)
```

## 8. 分隔线

三种写法之一（`*`、`-`、`_`），三个以上就行：

```md
上面一段话

---

中间一条分隔线（上面是空行哦）

***

再一条分隔线
```

⚠️ **注意**：如果分隔线上方紧跟文字，有可能被解析器当成 H2 标题语法（`---` 上一行是 `文字` 的话，就变 H2 了）。所以分隔线要和上文**空一行**最稳。

## 9. 转义字符（特殊符号不被解析）

你想写一个字面的 `*星号*` 但不要它变斜体，就在前面加 `\` 反斜杠：

| 你想写出来的字符 | 用反斜杠转义 | 效果 |
|---|---|---|
| `*` | `\*` | \* |
| `**` | `\*\*` | \*\* |
| `` ` `` | `` \` `` | \` |
| `#` | `\#` | \# |
| `[]()` | `\[\]\(\)` | \[\]\(\) |
| `>` | `\>` | \> |
| `_` | `\_` | \_ |
